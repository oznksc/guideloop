# Vite + React example

SPA starter for GuideLoop with **spotlight shapes**, **multi-target highlights**, and the **Debug HUD**.

## Features

- `spotlightShape: 'circle' | polygon`
- `additionalTargets` multi-spotlight
- `debug` forced on so the HUD is visible while developing

## Run

```bash
# from repo root
npm run build

cd examples/vite-react
npm install
npm run dev
```

Open [http://localhost:3101](http://localhost:3101) and click **Start tour**.
